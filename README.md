# E-Commerce Sales & Customer Analytics Dashboard

An end-to-end **Data Analytics project** analyzing e-commerce sales, profitability, customer segments, regions, products, and payment methods.

### 🔄 Project Workflow

**Excel → SQL → Python → Power BI → Business Insights**

## 🛠️ Tools Used

* Excel
* MySQL
* Python
* Pandas
* NumPy
* Matplotlib
* Power BI
* GitHub

## 📊 Dashboard Preview

![E-Commerce Sales Dashboard](dashboard.png)

## 💡 Business Insights

* **Electronics** generated the highest overall sales and profit.
* **West** was the highest-performing region by sales.
* **Consumer** customers generated the highest sales and profit.
* **UPI** was the leading payment mode by sales.
* **Laptop** was the top product by both sales and profit.
* Overall profit margin was approximately **21.86%**.
* **21 loss-making orders** were identified with a total loss of **₹47,750**.
